# Poster assets

Place approved, poster-ready assets in this directory. Keep raw/source material elsewhere and export only the selected high-resolution versions here.

## Naming convention

`<category>_<subject>_<view-or-state>_v<nn>.<ext>`

Examples:

- `hardware_node_v3_front_v01.png`
- `hardware_fieldhub_v2_front_v01.png`
- `ui_dashboard_overview_v01.png`
- `ui_fieldhub_pairing_v01.png`
- `diagram_architecture_v01.svg`
- `diagram_deployment_mosaic_v01.svg`

## Needed

- [ ] node hardware photo, clean background
- [ ] FieldHub hardware photo, clean background
- [ ] current dashboard overview screenshot
- [ ] current local setup/pairing screenshot
- [ ] architecture diagram
- [ ] hypothetical deployment illustration
- [ ] calibration/reference photograph
- [ ] FieldMesh logo or text lockup
- [ ] QR code after the destination is locked

## Export guidance

- Prefer SVG or PDF for diagrams and logos.
- Use PNG or TIFF for screenshots and photographs; avoid JPEG recompression where practical.
- At final placed size, raster assets should normally be at least 150 dpi and ideally 200–300 dpi.
- Remove private project names, access keys, precise site coordinates and other sensitive data from screenshots.
- If a screenshot uses synthetic data, label it “demonstration data” in the figure caption.
